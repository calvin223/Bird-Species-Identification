# Bird images

One photo per species, shown by the web interface next to each identification. Files are named after the species in lowercase with underscores (`european_robin.jpg`). `out_of_scope.png` is shown for low-confidence results and whenever an image fails to load.

## Credits

The photos were collected automatically from Wikimedia Commons, GBIF and Flickr public feeds for use in this university project. Attribution for individual images was not recorded. If you own one of these images and would like it credited or removed, please open an issue.
